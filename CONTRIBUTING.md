# Contributing

You do not need to be a programmer to help.

Useful early contributions include a task you wish to automate, confusing setup steps, documented connection results, and corrections supported by official sources.

For a problem report, describe what you wanted, your software versions, the exact steps, what happened, and what you expected. Use the [testing journal template](docs/testing-journal.md) for repeatability.

Please distinguish observations from assumptions. Use disposable designs for experiments and share only files you have permission to publish. Do not post credentials or confidential project data.

Before proposing substantial code, open an issue to agree on scope and resolve the project's pending license choice. Keep proposed changes focused on demonstrated needs.
