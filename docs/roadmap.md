# Roadmap

Unchecked items are planned, not completed.

## 1. Establish the project

- [x] Draft purpose, initial research, and test plan.
- [ ] Select a reuse license before substantial external code contributions.
- [ ] Record Fusion version, license category, operating system, and OpenAI client version without private account details.

## 2. Prove the desktop connection

- [ ] Confirm the Fusion MCP option exists and enable it.
- [ ] Configure the local OpenAI client.
- [ ] Discover tools and record their supported operations.
- [ ] Read the active document and capture a view.

Success: a documented read operation succeeds through the actual connection.

## 3. Validate one complete workflow

- [ ] Create a mounting bracket in a disposable document.
- [ ] Change a named dimension and verify the measured result.
- [ ] Save and export STEP; reopen and inspect the export.
- [ ] Record failures and recovery behavior.
- [ ] Repeat the guide from a fresh session.

Success: a second run reproduces the requested dimensions and a valid export.

## 4. Make it useful to others

- [ ] Publish a beginner setup guide based on observed results.
- [ ] Add sample prompts and non-sensitive screenshots.
- [ ] Collect independent setup reports.
- [ ] Package reusable workflows if they materially improve reliability.

## 5. Assess browser access

- [ ] Confirm account permissions and tunnel availability.
- [ ] Test the same workflow through ChatGPT web.
- [ ] Resolve screenshot delivery, export access, disconnects, and document selection.
- [ ] Compare results and maintenance effort with the desktop route.

Public plugin distribution and multi-user hosting require a separate design decision after these milestones.
